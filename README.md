# NEXO PLAN — actualizaciones semanales

Este repositorio alimenta la app **NEXO PLAN** de NEXO PC ("Excelencia digital, confianza real").

La app descarga este archivo y suma los temas de las semanas nuevas:

```
https://raw.githubusercontent.com/nexopc/nexo-plan/main/plan.json
```

- `plan.json`: el plan que lee la app (temas por semana + mensaje de la semana).
- `fuente/`: las metas, los temas de las semanas 1–12 y la rutina de ejercicio que ya vienen dentro de la app.
- `CONTEXTO.md`: reglas para escribir cada semana nueva.
